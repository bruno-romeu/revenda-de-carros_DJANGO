## Descrição

Este é um sistema simples de gestão de **revenda de carros**, construído com Django. Ele permite:

- cadastrar novos carros;  
- listar carros cadastrados;  
- editar dados de carros existentes;  
- excluir carros do banco de dados.

O objetivo principal é servir como projeto de aprendizado do Django, aplicando conceitos de CRUD, modelos, views, urls, templates, manipulação de arquivos estáticos e de mídia, autenticação básica, etc.

---

## Funcionalidades

- CRUD (Criar, Ler, Atualizar, Deletar) de carros  
- Upload de imagens dos carros  
- Autenticação de usuários (login / logout)  
- Interface básica para administração
